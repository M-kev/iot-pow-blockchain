## 3. DPoS Consensus Flow

```
┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                    DPoS CONSENSUS MECHANISM                                     │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘

Time-based Validator Rotation:
┌─────────────┬─────────────┬─────────────┬─────────────┬─────────────┬─────────────┬─────────────┐
│ Block 0     │ Block 1     │ Block 2     │ Block 3     │ Block 4     │ Block 5     │ Block 6     │
│ pi_node_1   │ pi_node_2   │ pi_node_3   │ pi_node_4   │ pi_node_5   │ pi_node_6   │ pi_node_1   │
└─────────────┴─────────────┴─────────────┴─────────────┴─────────────┴─────────────┴─────────────┘

Validator Selection Formula:
V(t) = delegates[floor(t / block_time) % len(delegates)]

Block Creation Process:
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Check if      │───▶│   Collect       │───▶│   Create Block  │───▶│   Broadcast     │
│   Current       │    │   Pending       │    │   with Energy   │    │   via MQTT      │
│   Validator     │    │   Transactions  │    │   Metrics       │    │                 │
└─────────────────┘    └─────────────────┘    └─────────────────┘    └─────────────────┘
```
